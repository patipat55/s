# Shopee Flash Helper (Android)

แอป Android (Kotlin + Accessibility Service) ช่วยกดซื้อสินค้าช่วงแฟลชเซล

## ทำอะไรได้
- ซิงก์เวลากับ NTP (time.google.com)
- เลือกสี/ไซส์ล่วงหน้า แล้วกดซื้อทันทีเมื่อถึงเวลาเซล
- เจอหน้ายืนยันตัวตน (จิ๊กซอว์) จะหยุด สั่น และมีเสียงเตือน ให้ผู้ใช้เลื่อนเอง
- ทำต่อจนถึงหน้าชำระเงิน แล้วหยุดให้ผู้ใช้จ่ายเอง

## วิธี build
**แบบไม่ต้องใช้คอม (GitHub Actions)**
1. อัปโหลดโปรเจกต์ทั้งหมดขึ้น repo (รวมโฟลเดอร์ `.github`)
2. ไปแท็บ Actions > Build APK > Run workflow (หรือ push เข้า main)
3. รอจบ แล้วโหลดไฟล์ `shopee-flash-helper-apk` ในหัวข้อ Artifacts ได้ `app-debug.apk` ลงมือถือ

**แบบใช้ Android Studio**
เปิดโฟลเดอร์นี้ แล้วกด Run ลงมือถือ (minSdk 26)

## วิธีใช้
1. ติดตั้ง APK แล้วเปิดสวิตช์ Shopee Flash Helper ในเมนู การช่วยเหลือพิเศษ
2. ใส่เวลาเซล + สี/ไซส์ กด "เริ่มรอเซล"
3. เปิดแอป Shopee ที่หน้าสินค้าค้างไว้

## ข้อควรรู้
- ข้อความปุ่ม/คำตรวจจิ๊กซอว์ แก้ได้ใน `Bot` ด้านบน `ShopeeBotService.kt`
- ไม่ได้เลี่ยงหรือแก้จิ๊กซอว์ให้ ผู้ใช้ต้องเลื่อนเอง
- การใช้บอทกดซื้ออาจขัดเงื่อนไขของ Shopee ใช้ด้วยความเสี่ยงของตัวเอง
